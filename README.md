# NeuroVasc

This repository is the companion to the paper **"Nociceptive interoception drives a self-reinforcing neurovascular circuit in aortic dissection"**. It contains the processed data (underlying evidence for all figures and tables) and the R code used for the analyses presented in the paper, including:

- 🧬 Bulk transcriptome data of aortic tissues from healthy individuals and patients with acute and chronic aortic dissection
- 📊 All R scripts used for data analysis

## Repository structure

```
.
├── data/                        # Processed data (evidence files)
│   └── bulk data/               # Bulk transcriptome data
├── scripts/                     # Analysis code (R)
└── README.md
```
